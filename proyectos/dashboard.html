¿Qué hace este proyecto?
Componentes principales del dashboard

Base de Datos Estructurada

Tabla con columnas: Fecha, Mes, Categoría, Producto, Cantidad y Precio. Lista para conectar con tabla dinámica.

Tabla Dinámica

Resumen automático de ventas agrupadas por categoría con totales de unidades e ingresos.

Segmentación de Datos

Filtros visuales interactivos por Mes y Categoría que actualizan toda la tabla y el gráfico al instante.

Gráfico Dinámico

Gráfico de barras vinculado a la tabla dinámica que cambia automáticamente al aplicar cualquier filtro.

Cómo se construyó
Paso a paso en Excel
01

Base de Datos

Se creó una tabla con encabezados: Fecha, Mes, Categoría, Producto, Cantidad, Precio Unit. y Total. Se formateó como Tabla de Excel (Ctrl+T) para que sea dinámica.

02

Tabla Dinámica

Insertar → Tabla Dinámica. Se colocó Categoría en Filas, y Cantidad + Total en Valores. Se aplicó formato de moneda a la columna de ingresos.

03

Segmentadores

Con la tabla dinámica activa: Insertar → Segmentación de Datos → se seleccionaron los campos Mes y Categoría. Se conectaron ambos al mismo gráfico.

04

Gráfico Dinámico

Insertar → Gráfico Dinámico → Barras agrupadas. Se limpió el diseño, se quitaron líneas de cuadrícula y se asignó la paleta de colores corporativa.

Fórmulas Clave
Las funciones usadas para complementar la tabla dinámica
Total por fila
=[Cantidad]*[Precio Unit.]
Columna calculada dentro de la tabla. Al ser Tabla de Excel, la fórmula se replica automáticamente en cada fila nueva.
Ventas por categoría
=SUMAR.SI.CONJUNTO([Total],[Categoría],E2,[Mes],F2)
Suma el total solo cuando coinciden la categoría y el mes seleccionados. Útil como respaldo fuera de la tabla dinámica.
% del total
=B2/SUMA($B$2:$B$10)
Calcula qué porcentaje representa cada categoría sobre el total general. Se formatea como porcentaje con 1 decimal.
Extraer mes de fecha
=TEXTO(A2,"mmm")
Convierte la fecha completa en la abreviatura del mes (Ene, Feb, Mar…) para usarla como campo de segmentación.
